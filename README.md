# ATS Resume Analyzer Pro

A professional ATS (Applicant Tracking System) Resume Analyzer that helps job seekers evaluate their resumes against common ATS screening criteria used by recruiters and hiring platforms.

The application allows users to upload PDF or DOCX resumes and receive a detailed ATS compatibility report, including resume scoring, section validation, formatting analysis, keyword evaluation, recruiter insights, and actionable improvement suggestions.

## ATS Evaluation Parameters

The analyzer evaluates resumes using multiple ATS-friendly criteria:

| Category             | Points |
| -------------------- | ------ |
| Contact Information  | 10     |
| Section Headers      | 15     |
| Formatting           | 10     |
| Content Length       | 10     |
| Dates Detection      | 10     |
| Action Verbs         | 10     |
| Resume Length        | 10     |
| Quantifiable Results | 15     |
| Online Presence      | 10     |
| Resume Structure     | 10     |

Final ATS Score is normalized to a scale of 100.
